# Hábito App Base

Proyecto base en Flutter para iniciar la app móvil de Hábito.

## Cómo usar
1. Descomprime el ZIP.
2. Abre la carpeta en VS Code o Android Studio.
3. Ejecuta:

```bash
flutter pub get
flutter run
```

## Incluye
- Login base
- Navegación inferior
- Inicio
- Tienda
- Citas
- Puntos
- Perfil
